# พร้อมยื่น — ผู้ช่วยเตรียมข้อมูลแจ้งความ

เว็บภาษาไทยแบบ static สำหรับ GitHub Pages ไม่มี backend และคงหน้าตาแชตเดิมไว้

## การใช้งาน

1. เข้าใช้งานบนเครื่องนี้และวาดลายมือชื่อ หรือเพิ่มภายหลังใน **ข้อมูลและความเป็นส่วนตัว**
2. อัปโหลดภาพบัตรประชาชนหรือคิวอาร์ใบขับขี่ กดอ่านข้อความ/คิวอาร์ ตรวจแก้ข้อมูล แล้วกดยืนยันบันทึก
3. เลือกหัวข้อ ตรวจรายการเอกสารที่เลือกให้อัตโนมัติ และตอบเฉพาะข้อมูลที่ขาด
4. เปิดตรวจร่าง เลือกจุดเกิดเหตุและสถานีตำรวจ หรือระบุสถานีเองเมื่อใช้แผนที่ไม่ได้
5. บันทึกร่าง แล้วพิมพ์เป็นกระดาษ A4 หรือบันทึกเป็นพีดีเอฟ พร้อมสำเนาภาพที่มีคำรับรอง วันที่ พ.ศ. และลายมือชื่อ

เอกสารนี้เป็นร่างเตรียมข้อมูล ไม่ใช่แบบที่หน่วยงานรับรอง ไม่ส่งเรื่องจริงหรือออกเลขรับแจ้งความ

## ข้อมูลและบริการภายนอก

- เก็บ JSON เวอร์ชัน 2 เพียงรายการเดียวใน IndexedDB เดิม (`promptyuen-free-v1` / `workspace` / `state`): `{version, docs:{type:{fields,image,updated,...}}, signature, cases}`
- เอกสารใหม่รอตรวจในหน่วยความจำก่อนบันทึก เอกสารประเภทซ้ำต้องยืนยันแทนที่ คำขออ้างอิงข้อมูลเอกสารล่าสุดตามประเภท
- อัปเกรดข้อมูลรุ่นเก่าอัตโนมัติ หากมีเอกสารประเภทเดียวกันหลายฉบับจะใช้ฉบับล่าสุดตามลำดับในคลังเดิม ควรสำรองข้อมูลก่อนอัปเกรด
- OCR ทำในเบราว์เซอร์ โหลด Tesseract.js 6.0.1 / core 6.0.0 / ชุดภาษา 4.0.0 เมื่อใช้เท่านั้น; คิวอาร์โหลด jsQR 1.4.0 เมื่อใช้
- เบราว์เซอร์อ่านชิปบัตรไม่ได้ คิวอาร์ DLT แบบลิงก์ รหัสทึบ หรือข้อมูลเข้ารหัสให้กรอกเอง ไม่อ้างว่าอ่านได้ทุกรุ่นหรือยืนยันเอกสารแท้
- ค้นหาสถานีด้วย Google Maps จากละติจูด/ลองจิจูดจุดเกิดเหตุ หรือชื่อสถานที่เมื่อไม่มีพิกัด เปิดลิงก์โดยผู้ใช้เท่านั้น ไม่ส่งคำบอกเล่าหรือหลักฐานไปกับลิงก์ เพิ่มการดึงผลจาก Places API (New) และเลือกสถานีที่ใกล้ที่สุดในผลค้นหาระยะ 50 กม. เป็นจุดยื่นเอกสารอัตโนมัติ (ระยะเส้นตรง ไม่ยืนยันเขตรับผิดชอบ) ต้องตั้งรหัส Google Maps สำหรับเบราว์เซอร์ เปิด Maps JavaScript API และ Places API (New) พร้อม billing และจำกัด HTTP referrer ให้ตรงเว็บไซต์ รหัสอยู่ใน sessionStorage เท่านั้น ไม่มีคีย์รวมใน repository; หากยังไม่ตั้งค่า ให้ระบุสถานีเองได้
- AI เรียบเรียงคำบอกเล่าเป็นสำนวนทางการผ่าน endpoint เดิม หลังผู้ใช้อนุญาต ส่งเฉพาะคำบอกเล่า วันเวลา และสถานที่ ผู้ใช้ตรวจแก้และยืนยันก่อนใช้ในใบสรุป เก็บต้นฉบับและประเด็นที่ยังต้องถามแยกไว้ หากข้อมูลต้นทางเปลี่ยนร่างเดิมจะใช้ไม่ได้
- ภาพอุบัติเหตุย่อเหลือไม่เกิน 1024 พิกเซล เป็น JPEG คุณภาพ 0.7 ก่อนส่ง **เฉพาะเมื่อผู้ใช้อนุญาต** ไปยังบริการ AI ที่ตั้งค่า อาจมีค่าใช้จ่ายตามบริการ
- ที่อยู่บริการ รหัสเข้าใช้งาน และชื่อโมเดลอยู่ใน sessionStorage เท่านั้น ไม่รวมในคลังเอกสารหรือไฟล์ส่งออก บริการต้องรองรับ CORS และรูปแบบ `POST /v1/chat/completions` ที่รับภาพและคืน JSON
- ผล AI ต้องเป็น `{part, severity:1-3, summary_th, confidence:0-1}`; ผู้ใช้ตรวจแล้วจึงแนบได้ และทุกภาพมีป้าย **ผลประเมินเบื้องต้นโดย AI ไม่ใช่คำวินิจฉัยทางกฎหมาย**
- ปุ่ม **ล้างข้อมูลทั้งหมด** ลบเอกสาร ลายมือชื่อ คำขอ และการตั้งค่า AI ของแอปนี้ ไม่ลบข้อมูลของเว็บไซต์อื่น
- ผู้ใช้โปรไฟล์เบราว์เซอร์เดียวกันอาจเข้าถึงข้อมูลได้ หน้าเข้าใช้งานเป็นพื้นที่ในเครื่อง ไม่ใช่ระบบยืนยันตัวตน

## พัฒนาและทดสอบ

ไม่มีขั้นตอน build และไม่มี dependency ใหม่ที่ต้องติดตั้งเพื่อเปิดเว็บ:

```sh
python3 -m http.server 4173
node --test tests/*.test.mjs
```

เปิด `http://localhost:4173` เพื่อใช้งาน ชุดทดสอบใช้บริการ AI จำลอง ไม่เรียก endpoint จริง ไม่ต้องแตก tests.zip รุ่นเก่า
ตรวจด้วยตนเอง: ใส่พิกัดจุดเกิดเหตุ เปิดลิงก์ Google Maps แล้วกรอกชื่อสถานี; อนุญาต AI เรียบเรียง ตรวจข้อความและยืนยัน จากนั้นบันทึกและพิมพ์ใบสรุป

โค้ดแชต/ฟอร์มเดิมแยกจากไฟล์ bundle มาเป็น `assets/app.js`; `assets/shared-ui.js` ใช้ React และส่วนประกอบเดิม ไม่มีการย้าย framework ไฟล์ bundle เก่าเก็บไว้เพื่อไม่ให้เว็บรุ่นก่อนเสียระหว่าง deploy

GitHub Pages ใช้ branch `main` โฟลเดอร์ `/` และ `.nojekyll` เดิม เปิดผ่าน HTTPS เพื่อใช้ตำแหน่งและ IndexedDB ได้ตามปกติ
ดูรายการเปลี่ยนแปลงและวิธีทดสอบแต่ละฟีเจอร์ใน [CHANGELOG.md](CHANGELOG.md)

แหล่งอ้างอิง: [Tesseract.js](https://github.com/naptha/tesseract.js), [jsQR](https://github.com/cozmo/jsQR), [Google Maps URLs](https://developers.google.com/maps/documentation/urls/get-started)

ตรวจปุ่มส่งด้วยข้อมูลจำลองในเครื่อง: เปิด `tests/submission.html` จาก localhost เท่านั้น ผลสถานีในหน้านี้เป็น mock; เว็บจริงใช้ Google Places ไม่มีรายชื่อสถานีสมมุติแทนผลจริง
