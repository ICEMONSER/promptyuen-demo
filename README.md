# พร้อมยื่น — รุ่นทดลองฟรี

เว็บต้นแบบภาษาไทยสำหรับนำข้อมูลเอกสารกลับมาใช้เตรียมคำขอหลายประเภท โดยไม่มี AI API แบบเสียเงิน

## ทดลองใน 2 นาที

1. กด **ลองด้วยข้อมูลตัวอย่าง** หรืออัปโหลด `sample-document.png`
2. หากอัปโหลดภาพ ให้กดอ่านภาพด้วย OCR ตรวจข้อมูล แล้วกดยืนยัน
3. เลือกเรื่อง เช่น แจ้งความ / ลงบันทึก อนุญาตเฉพาะเอกสารที่ต้องการใช้
4. ตอบคำถามที่ยังขาด หรือเปิดตรวจร่างเพื่อแก้ไขเอง
5. ตรวจร่าง แล้วส่งแบบจำลอง หรือพิมพ์/บันทึกเป็น PDF และดาวน์โหลด JSON

## ขอบเขตสำคัญ

- ไม่เชื่อมฐานข้อมูลรัฐ ไม่ส่งเรื่องจริง และแบบร่างไม่ใช่แบบฟอร์มที่หน่วยงานรับรอง
- รุ่นฟรีใช้ OCR ในเบราว์เซอร์และบทสนทนาแบบนำทาง ไม่ใช่ AI สนทนา
- เอกสารและคำขอเก็บใน IndexedDB ของเบราว์เซอร์เครื่องนั้น ไม่ส่งให้ GitHub ไม่มีระบบบัญชีหรือซิงก์ข้ามเครื่อง
- ใช้ข้อมูลจำลองเท่านั้นในช่วงทดลอง ไม่ใช่คลังเอกสารจริงที่ผ่านการตรวจความปลอดภัยแล้ว
- ผู้ใช้เครื่อง/โปรไฟล์เดียวกันอาจเข้าถึงข้อมูลได้ การล้างข้อมูลเว็บจะทำให้ข้อมูลหาย
- OCR และฟอนต์โหลดจากเครือข่ายในครั้งแรก ผู้ให้บริการไฟล์เหล่านั้นอาจเห็นข้อมูลการเชื่อมต่อตามปกติ แต่แอปไม่ส่งภาพให้บริการ OCR ภายนอก
- รูปภาพอ่านด้วย OCR ได้ ส่วน PDF เปิดเทียบและกรอกข้อมูลเอง ความถูกต้องต้องให้ผู้ใช้ตรวจ
- ลบเอกสารและลบคำขอแยกกัน สำเนาข้อมูลในคำขอไม่ถูกลบพร้อมเอกสารต้นฉบับ
- ไม่ต้องมี API key บัตรเครดิต หรือสมัครบริการแบบเสียเงิน

## ไฟล์เว็บ

`promptyuen-free-site.zip` เป็นเว็บที่สร้างเสร็จแล้ว เหมาะกับ GitHub Pages เปิดผ่านเว็บเซิร์ฟเวอร์ ไม่เปิด `index.html` ด้วย file:// โดยตรง

`promptyuen-source.zip` เป็นซอร์สสำหรับพัฒนาต่อ ไม่มี API key ฐานข้อมูล หรือเอกสารที่ผู้ใช้อัปโหลด ใช้ Node.js 22 ขึ้นไป ติดตั้ง dependencies แล้วรัน `npm run dev:free` หรือ `npm run build:free` ผลลัพธ์อยู่ใน `dist-static` รุ่นฟรีนี้ไม่เรียก backend/OpenAI

## ความพร้อมสำหรับการแข่งขัน

ต้นแบบแสดงขั้นตอนยินยอม อ่านเอกสาร ตรวจข้อมูล เติมข้อมูลพร้อมแสดงที่มา ตรวจร่าง และส่งจำลองได้ ยังต้องเพิ่ม AI สนทนาที่ได้รับอนุมัติงบประมาณ/สิทธิ์ใช้งานหรือโมเดลในเครื่อง และประเมินความถูกต้องก่อนอ้างว่าเป็น AI Concierge เต็มรูปแบบ

เอกสารนำเสนอและวิดีโอประกวดไม่ได้รวมอยู่ในชุดเว็บนี้
