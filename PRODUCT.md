# พร้อมยื่น

<!-- impeccable:product-schema 1 -->

## Platform
web

## Users
Crime victims preparing information and documents for a police report, mostly on mobile and under stress. This is the user's explicit brief.

## Product Purpose
Help people describe an incident, review a draft statement, gather evidence and select a police station before visiting it.

## Capabilities and Constraints
Preserve voice incident capture, WebLLM statement drafting, ID OCR, the 88-station Leaflet picker, evidence attachments, simulated submission, and Supabase case tracking. Static index.html + assets/, no build step, GitHub Pages on main at root. Thai UI only. No paid API or API-key requirement for local drafting. This is a demonstration, not a real police report or an authority-certified form.

## Brand Commitments
พร้อมยื่น. Trustworthy, calm and clear. Viriyah's live color tone and aiinsurance.io's live structure are binding references. Never copy reference logos, images or text. Anti-references: fake police authority and generic AI styling.

## Product Principles
- Make preparation understandable under stress.
- Preserve working functionality and integration hooks.
- Explain limitations without inventing authority or proof.
- Use only real figures and verified privacy claims.

## Accessibility & Inclusion
Mobile-first at 390px. Readable Thai typography, keyboard access and WCAG AA contrast.

## Open Decisions
No interview is required: the user explicitly requested one-pass execution without questions. No additional product facts have been inferred.
